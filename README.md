# MIPS64 Assembly Exercises

WinMIPS64 汇编练习合集，覆盖整数运算、循环、递归、排序、阶乘、数列和基础 I/O。

## 文件

| 文件 | 内容 |
|---|---|
| `factorial.s` | 阶乘 |
| `hail.s` | 冰雹数列 / Collatz 过程 |
| `isort.s` | 插入排序 |
| `mult.s` | 乘法 |
| `series.s` | 数列求和 |
| `sum.s` | 数组求和 |
| `test_for.s` | 循环控制 |
| `testio.s` | 输入输出 |
| `21.s` / `22.s` | 练习版本 |
| `2_1.s` / `2_2.s` | 实验二练习 |

## 工具

- WinMIPS64 模拟器
- MIPS64 汇编

仓库不包含 `winmips64.exe`、安装说明和模拟器其它二进制文件。

## 运行

1. 安装 WinMIPS64 或兼容的 MIPS64 模拟器。
2. 打开对应的 `.s` 文件。
3. 汇编并运行。
4. 在寄存器、数据段和流水线窗口中观察执行结果。

## 说明

- 这些代码是课程练习，不同模拟器版本的伪指令支持可能不同。
- `test_for.txt` 是配套的测试说明/输出样本。
- 程序通常包含固定的数据段和测试输入，便于课堂演示。
